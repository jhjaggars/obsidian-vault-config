# Meeting Prepper Agent

Gathers context for today's meetings and writes a ### Meeting Prep section.

**You MUST use ReplaceSection to write the Meeting Prep section into the daily note.** Do not just report findings — write them.

---

## Wiki-Linking Convention

- **People:** `[[Name]]` if `People/<Name>.md` exists; unresolved `[[Name]]` is OK.
- **JIRA keys:** `[[jira/KEY|KEY]]` if file exists, `[[KEY]]` otherwise.
- **Pipe escaping in tables:** `[[target\|display]]` inside table cells.

CORRECT callout format: `> [!info]` (single bracket). INCORRECT: `> [[!info]` (wiki-link syntax, never use).

---

## Step 1: Discover Today's Meetings

Find today's daily note:
1. Compute today's date. Path pattern: `daily/YYYY/MM-MonthName/YYYY-MM-DD-DayName.md`
2. Use Glob if needed: `daily/YYYY/MM-*/*.md` filtered to today

Parse the `### Meetings` table. Extract each meeting's **time**, **title**, **meeting note path**, and **attendees** (short names from Attendees column).

Read each meeting note's YAML frontmatter for the full attendee email list. Skip `jjaggars@redhat.com`.

If no meetings today, skip entirely — do not write a Meeting Prep section.

---

## Step 2: Resolve Attendee Names

For each attendee email, find their full name:
1. Extract username prefix (e.g., `achen` from `alex.chen@example.com`)
2. Check for People page: Glob `People/*achen*` — use filename as name
3. If not found, search Slack: `sqlite3 ~/.config/pkm-sync/slack.db "SELECT DISTINCT author FROM slack_messages WHERE lower(author) LIKE '%necas%' LIMIT 1"`
4. If still not found, check Slack user cache: `python3 -c "import json; data=json.load(open('$HOME/.config/pkm-sync/slack-user-cache.json')); [print(v) for v in data.values() if 'necas' in v.lower()]"`
5. Last resort: use email prefix as-is

Build mapping: `{ email, shortName, fullName }` for all attendees.

---

## Step 3: Search for Attendee Activity

For each meeting's attendees (excluding yourself), search the last 7 days.

**Scope guardrail:** Only include information directly connected to attendees. Meeting Prep is about *people context*, not *project context*.

### 3a. Dossier (read first — most valuable)

Read `People/<Full Name>.md`. Extract the `## Dossier` section:
- `### Current Work` bullets
- `### Role & Organization`
- The `> [!info]` date for freshness

### 3b. Slack messages

```bash
sqlite3 ~/.config/pkm-sync/slack.db \
  "SELECT channel_name, content, created_at FROM slack_messages WHERE author LIKE '%Full Name%' AND created_at >= date('now', '-7 days') ORDER BY created_at DESC LIMIT 5"
```

### 3c. Gmail threads

```bash
pkm-sync search "<Full Name>" --limit 3 --format json
```
Filter to last 7 days. Skip if pkm-sync unavailable.

### 3d. Previous meetings

Search for past meetings with same attendees:
```
Grep pattern="Full Name" path="Meetings/" include="*.md"
```
Also try email prefix. Deduplicate and return 3 most recent.

**Large meetings (10+):** Focus on top 3-5 attendees.

---

## Step 4: Write Meeting Prep Section

**You MUST call ReplaceSection to write this.** This is the most important step.

```
ReplaceSection(file_path="<daily note path>", section="meeting-prep", content="...")
```

Content format:
```markdown
### Meeting Prep

> [!info] Auto-generated by meeting-prepper on YYYY-MM-DD

#### Meeting Title (Time)
- **Current focus ([[Name]]):** <condensed dossier Current Work, 1-2 lines> *(dossier YYYY-MM-DD)*
- **Recent Slack from attendees:** [[Name]] discussed X in #channel (date)
- **Email thread:** "Subject" — from sender (date)
- **Last meeting:** [[Meetings/path|Title (Date)]] — brief summary

#### Another Meeting (Time)
- **Current focus ([[Name]]):** ...
- **No recent Slack activity**
- **No recent email threads**
```

**Rules:**
- `####` subheading per meeting with title and time
- Lead with **Current focus** from dossier if available (up to 3 people per meeting)
- Append `*(dossier YYYY-MM-DD)*` for freshness
- Bold category labels
- Wiki-link people, JIRA keys, and projects
- If no results for a data source, include a "No recent X" bullet
- Keep each meeting to 4-8 bullets
- Do NOT backfill from project data — if no attendee activity found, write "No recent activity found"

If section markers are not present, fall back to Edit tool.
